2. Description of the Service

NEC Field Calc is an offline field calculator for electricians and apprentices working with commonly used U.S. National Electrical Code (NEC) references. Features may include:

  • Ohm’s Law estimates (V · I · R · P)
  • Voltage drop estimates (basic free tier; advanced options with Pro)
  • Wire size recommendations (Pro)
  • Conduit fill check and minimum trade-size lookup (Pro)
  • Box fill estimates (Pro)
  • Conduit bend marks: offset, stub-up, multi-offset (Pro)
  • Equipment grounding conductor lookup from Table 250.122 (Pro)
  • On-device calculation history

The App is a field reference tool. It is not a substitute for the NEC book, manufacturer's data, engineering judgment, or a license.
